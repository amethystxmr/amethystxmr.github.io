# Amethyst XMR Monero wallet

## Building wasm module

(check CI for the most up-to-date instructions)

```bash
cd monero-wasm-src
./init.sh
./build.sh
```

(If you have emsdk in your home folder then it will use it, docker overwise)

## Building web

```
npm run build

# or for local development
npm run dev
```
